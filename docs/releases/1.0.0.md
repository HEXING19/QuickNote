QuickNote · 随手记的首个版本。一张长期保留、随时续写的本地草稿纸。

### 功能

- 屏幕右侧纸笔入口，点击展开，可上下拖动。
- 同一份纯文本草稿，自动保存；收起、跨天和重启后继续保留。
- Esc 收起、固定窗口、菜单栏入口和可选全局快捷键。
- 本地原子写入、文件校验、上一份副本和定期备份。
- 备份恢复、纯文本导出；保存失败时保留输入并重试。

### 下载

- **QuickNote-1.0.0-universal.dmg**：推荐；打开后将 App 拖到 Applications。
- **QuickNote-1.0.0-universal.zip**：解压即可获得 QuickNote.app。
- **SHA256SUMS.txt**：用于校验上述文件。

macOS 13+，包含 Apple Silicon（arm64）与 Intel（x86_64）。

- 5 项数据保护测试通过；已验证中文文本、收起续写、重启恢复和保存失败后自动重试。
- 两种架构构建完成，App 严格签名检查通过；Intel 实机尚未验证。
